# 生存日誌（自製版）

照著 Steam 遊戲《Survival Log》的玩法做的個人版本，只做給自己玩。

> 你死過一次。醒來時，時間回到早上 08:00。18:00，屍群會淹沒整座城市。

## 怎麼玩

不用安裝任何東西：下載 `index.html`，用瀏覽器打開就能玩。手機和電腦都可以。

- **準備期 10 小時**：在 8 個地點之間移動、採購。移動和結帳都會花時間。
- **背包負重 25kg**：東西要帶回家才算數。買車可以多 80kg，移動時間也大約減半。
- **大型設備送貨到府**：16:00 之後就送不到了。
- **定時事件**：搶購潮、漲價、缺水、關店。
- **爆發後守家（M2）**：一天一天自己操作，目標撐過 100 天。
  - 狀態值：生命、飽足、水分、體力、心態。醒著每小時都會下降。
  - 做事每項 1 小時：煮飯、加固防線、開發電機、踩人力發電機、種菜、休息。
  - 睡前結算太陽能和設備耗電（冷氣、冰櫃、種植箱）；新鮮食物會壞，冰櫃有電時壞得慢。
  - 屍潮夜可以選擇守夜：傷害 -40%，會邊打邊用材料修，但體力回得少。
  - 第 22–35 天寒潮、第 40 天後陰雨。
- **日誌**：會記下遇過的事件、去過的店和死因。規劃點數可以換更多時間、錢或背包容量。紀錄存在瀏覽器的 localStorage。

日誌分頁底下有「開發者模式」，可以加錢、倒轉時間、清空紀錄。

## 檔案

- `index.html`：遊戲本體，單一檔案，不需要任何外部套件。資料表（物品、商店、事件、屍潮時程）寫在檔案開頭的「資料表」區塊，平衡數值只需要改那裡。

# 生存日誌（自製版）

照著 Steam 遊戲《Survival Log》的玩法做的個人版本，只做給自己玩。

> 你死過一次。醒來時，時間回到早上 08:00。18:00，屍群會淹沒整座城市。

## 怎麼玩

不用安裝：下載 `index.html` 用瀏覽器打開就能玩，手機和電腦都可以。進度存在瀏覽器裡，關掉再打開可以繼續。標題畫面有 3 個存檔欄位，每格有自己的日誌、角色和進行中的一輪。

遊戲內「日誌」分頁有完整的遊戲說明，第一次進入各階段也會跳出提示。

## 遊戲內容

### 準備期（爆發前 10 小時）
- 8 個地點，移動、結帳、卸貨都花時間。背包 25kg，買車多 80kg、移動減半。
- 大型設備送貨到府，16:00 後送不到。
- 定時事件：10:32 搶購潮（超市免費拿）、漲價、缺水、關店。

### 爆發後守家
- 狀態值：生命、飽足、水分、體力、心態。前 5 天自來水還能喝。
- 做事每項 1 小時：煮飯與料理、加固、發電、種植、休息、製作、擴建、外出。
- 電力：太陽能、柴油發電機、人力發電、儲電站；冷氣、冰櫃、種植箱、機器人、電動陷阱都吃電。
- 屍潮：陷阱和燃燒瓶先擋，剩下打在防線上。可以守夜減傷。防禦等級 2 解鎖電擊陷阱、4 解鎖電鋸陷阱。
- 天氣與天災：第 22–35 天寒潮、第 40 天後陰雨；水管爆裂、鼠患、生病、電線走火、漏雨。

### 據點與製作
- 工作台：花盆、尖刺路障、噪音器、燃燒瓶、無人機自動化（基本），雨水收集器、太陽能板、暖爐、電擊陷阱、電鋸陷阱、釀酒機、雷達、精煉機、三種機器人（圖紙）。
- 製作熟練度：做 5 件體力 -25%，做 12 件時間 -1 小時。
- 擴建二樓、地下室；房間：儲藏室、溫室、工坊、臥室、發電室。倉庫有容量上限。
- 加工：榨汁機（果汁是交易熱門貨）、釀酒機（高度酒 → 燃燒瓶）、精煉機（油菜籽 → 柴油）。
- 機器人：澆水（作物 6 天成熟、產量 +25%）、修理（每晚修防線）、料理（早上自動煮飯）。

### 外出與其他倖存者
- 廢棄超市、學校、五金行；探索等級 2 開醫院、3 開科技公司、4 開上鎖的房間。醫院和科技公司要用噪音器。
- 暴露值滿 100% 會被包圍。雷達和狗可以降低暴露值、多找到東西。
- 無人機（學校教師辦公室）：每天交易、空投；裝自動化模組後會自動交易。
- 救援：隔壁的 Zoe、貨車裡的倉庫經理。流浪狗可以收養，每天餵會升級。

### 周目、結局與收集
- 每個存檔 3 次復活；死掉可以花規劃點數回溯到最近 7 天，或用掉復活重來。
- 天賦（當輪）：致命陷阱、耐力、暖身、園藝、廚藝、強韌。生存點數存到 200 以上每天有 5% 利息。
- 5 個角色：鄰居、大學生、倉庫經理、護理師、退伍軍人。
- 3 片真相碎片 → 4 種結局（黎明、真相、街坊、獨自倖存）。撐過 100 天可以進入無盡模式。
- 生存圖鑑、22 個成就、音效（可關閉）、手繪風場景插圖。

## 開發

原始碼在 `src/`，改完執行建置合成 `index.html`：

```
node build.js
```

- `src/template.html`：頁面骨架
- `src/style.css`：樣式
- `src/js/*.js`：依檔名順序合併。`00-data.js` 是物品、商店、事件、屍潮時程等資料表，平衡數值大多改這裡。

| 檔案 | 內容 |
| --- | --- |
| 00–02 | 資料表、日誌（跨輪保存）、工具函式 |
| 10–11 | 準備期規則與畫面 |
| 20 | 爆發後守家（狀態值、行動、睡前結算） |
| 30–31 | 死亡回溯復活、製作陷阱料理天災 |
| 40 | 外出、交易、救援、角色 |
| 50 | 據點擴建、加工、防禦等級、熟練度、結局、無盡 |
| 60 | 機器人、狗、雷達、精煉、噪音器、新角色 |
| 70 | 圖鑑與成就 |
| 80 | 插圖與音效 |
| 90–99 | 存檔續玩、新手教學、三個存檔欄位、事件綁定與啟動 |
